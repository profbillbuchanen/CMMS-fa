# سیستم مدیریت نگهداری و تعمیرات (CMMS)

یک وب اپلیکیشن حرفه‌ای برای مدیریت نگهداری و تعمیرات تجهیزات با UI/UX مدرن

## 🚀 ویژگی‌ها

- **داشبورد کامل** با نمودارها و آمارهای کلیدی
- **فونت فارسی وزیر متن** با پشتیبانی کامل از راست‌چین
- **طراحی ریسپانسیو** مناسب برای موبایل، تبلت و دسکتاپ
- **منوی کناری** با قابلیت جمع‌شدن
- **نمودارهای تعاملی** با Chart.js
- **جدول داده‌ها** با قابلیت مشاهده، ویرایش و حذف
- **تم رنگی حرفه‌ای** مشابه atlas-cmms.com

## 🛠 تکنولوژی‌های استفاده شده

- **Next.js 16** - فریم‌ورک React
- **TypeScript** - تایپ ایمنی
- **Tailwind CSS** - استایل‌دهی
- **Chart.js & react-chartjs-2** - نمودارها
- **Lucide React** - آیکون‌ها
- **Vazirmatn Font** - فونت فارسی

## 📦 نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه تولید
npm run build

# اجرای نسخه تولید
npm start
```
